# 席替え支援Webアプリ

教師向けの席替え支援Webアプリケーション。条件付きのランダム配置を高速に行い、設定画面と公開画面を分離した直感的なUIを提供します。

## 特徴

- **フロントエンドのみ**: GitHub Pagesで配信、サーバー不要
- **ローカル完結**: 外部送信なし、プライバシー保護
- **条件付きシャッフル**: ゾーン割当、近接ルール、固定席対応
- **直感的UI**: 初見で操作可能、学校風デザイン
- **データ永続化**: LocalStorage自動保存、Excel入出力

## 技術スタック

- **フレームワーク**: React 18 + TypeScript
- **ビルドツール**: Vite
- **状態管理**: Zustand
- **デザイン**: コトノルフォント + Apple HIG準拠
- **デプロイ**: GitHub Pages

## 開発環境セットアップ

### 必要環境

- Node.js 18+
- npm/yarn/pnpm

### セットアップ

```bash
# プロジェクト作成
npm create vite@latest seat-shuffle -- --template react-ts
cd seat-shuffle

# 依存関係インストール
npm install

# 開発サーバー起動
npm run dev
```

### 追加パッケージ

```bash
# 状態管理
npm install zustand

# ルーティング
npm install react-router-dom

# Excel処理
npm install xlsx

# アイコン
npm install lucide-react

# 開発ツール
npm install -D @types/node
```

## プロジェクト構造

```
src/
├── components/          # 再利用可能コンポーネント
│   ├── common/         # 汎用コンポーネント
│   ├── seat/           # 席関連コンポーネント
│   └── student/        # 生徒関連コンポーネント
├── views/              # ページコンポーネント
├── stores/             # Zustandストア
├── composables/        # 再利用可能ロジック
├── utils/              # ユーティリティ関数
├── types/              # TypeScript型定義
└── assets/             # 静的ファイル
```

## 主要機能

### 席配置管理

- 行×列の座席表作成・編集
- 空席設定（誰も座らない席）
- ゾーンの自由追加・色分け

### 生徒・グループ管理

- 生徒の追加・編集・削除
- グループ作成・メンバー割当
- 班長フラグ設定

### 条件設定

- ゾーン割当（グループ→ゾーン）
- 近接ルール（隣にしない/人一人挟む/隣にする）
- 固定席設定
- 部分シャッフル（特定グループのみ）

### シャッフル実行

- プレビュー→確定フロー
- 高速アニメーション演出
- 条件充足不可時の理由表示

### データ管理

- LocalStorage自動保存
- JSON/Excelバックアップ・復元
- 設定/公開画面分離

## デザインシステム

### フォント

- **コトノル**: モダンでスタイリッシュな日本語フォント
- 10段階のウェイト（Thin〜Black）
- 商用利用可能、JIS第二水準漢字対応

### カラー

- **セマンティック**: プライマリ・セカンダリ・サクセス・ワーニング・エラー
- **学校風**: 黒板・チョーク・ゾーン色分け
- **アクセシビリティ**: 4.5:1以上のコントラスト比

### コンポーネント

- Apple Human Interface Guidelines準拠
- 一貫性のあるデザイン言語
- アクセシビリティ対応

## 開発ルール

### コード品質

- TypeScript厳密使用
