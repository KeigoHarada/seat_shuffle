# 席替え支援Webアプリ 要件定義書（MVP）

最終更新: 2025-10-05

---

## 1. 目的 / 背景

- 教師が短時間で席替えを計画・実行できるようにする。
- 条件（配慮事項）を簡単に表現し、公平性と説明可能性を担保する。
- フロントエンドのみ・ローカル完結（GitHub Pages配信、外部送信なし）。

## 2. スコープ

- 機能要件・画面要件・非機能要件を定義。
- データモデル詳細・シャッフルアルゴリズム詳細は対象外（後続文書）。

## 3. 利用環境 / 前提

- 静的サイト（GitHub Pages）。
- LocalStorageによる自動保存、JSON/Excelバックアップ。
- PC優先、将来タブレット最適化検討。

## 4. 用語

- 席配置: 行×列の座席表。未使用席は「空席」登録可。
- ゾーン: 任意に作成できる座席グループ（例: 前方/後方/窓側/通路側/班）。
- グループ: 生徒の集合（1人は1グループのみ所属）。
- ロール: 班長などの役割（MVPは班長のみ）。
- 公開画面: 生徒向け表示用UI。
- 設定画面: 教師向け編集・入出力UI（ロック不要、表示切替のみ）。

## 5. 機能要件

### 5.1 席配置（行列ベース + 空席）

- 行数・列数を指定して座席表を作成/保存/複製/削除。
- 任意席を「空席」に設定/解除。
- 席にゾーンを付与（MVPは1席1ゾーン想定）。
- レイアウト名変更、並び替え、印刷プレビュー。

### 5.2 ゾーン管理

- ゾーンの追加/名称変更/削除。
- ゾーンの色/ラベル設定（公開画面で視認）。

### 5.3 生徒管理

- 生徒の追加/編集/削除（氏名、任意タグ）。
- 生徒は1つのグループにのみ所属可能。
- 班長フラグの付与（任意）。

### 5.4 グループ / ロール

- グループの作成/名称変更/削除。
- ロールは班長のみ（将来拡張余地）。

### 5.5 条件（UI指定、ロジック詳細は後続）

- ゾーン割当: 例: グループX → 指定ゾーン。
- 近接ルール: 「隣にしない」「人一人挟む（前後左右で最短1席空き）」「隣にする」。
  - 斜めは対象外（MVP）。
- 固定席: 生徒→特定席固定。
- 範囲適用: 全体/特定グループのみ対象に適用可。

### 5.6 シャッフル（実行・プレビュー）

- 対象範囲: 全体 / 指定グループ。
- プレビュー→確定で現配置に反映。
- 公開画面は「全員がランダムに動いたように見える」簡易演出。
- 充足不可時は簡潔な理由表示（例: 席不足）。
- 「ごきげんよう」の何が出るかなのBGMが流れて、シャッフルされる

### 5.7 画面分離 / 表示切替

- 設定画面と公開画面を分離。
- 設定画面はトグル/ショートカットで表示切替（ロックなし）。
- 公開画面は結果表示・印刷最適化。

### 5.8 データ永続化 / バックアップ

- LocalStorageへ自動保存。
- JSON/Excelエクスポートと同形式インポート（バリデーションあり）。

### 5.9 Excel入出力（外形）

- 1ブック複数シート: Students / Seats / Layouts / Groups / Conditions（仮）。
- 列定義詳細は後続で策定（MVPは最小から）。

### 5.10 印刷

- 公開画面から印刷。A4縦/横最適化（余白/枠線/フォントは後続）。

## 6. 非機能要件

- 性能: 40人前後を快適に。上限は実用上無制限（ブラウザ資源内）。
- セキュリティ/プライバシ: ローカル完結、外部送信なし。
- アクセシビリティ: コントラスト、キーボード操作、フォントサイズ調整。
- 保守性: 単純構成、将来拡張（タブレット、PWA）に耐える分離。

## 7. 画面一覧（MVP）

- 公開: 席表表示、シャッフル結果、印刷。
- 設定/席配置: 行列サイズ、空席指定、ゾーン付与、レイアウトCRUD。
- 設定/生徒・グループ: 生徒CRUD、グループCRUD、所属編集、班長フラグ。
- 設定/条件: ゾーン割当、近接、固定席、対象範囲選択。
- 設定/データ: 保存/復元、Excel/JSON入出力。

## 8. 操作フロー（例）

1) レイアウト作成（行×列）→空席指定→ゾーン作成/割当。
2) 生徒登録→単一グループ所属→必要に応じ班長設定。
3) 条件設定（ゾーン/近接/固定席、対象範囲）。
4) シャッフルをプレビュー→確定。
5) 公開画面で表示・印刷。

## 9. 受け入れ基準（抜粋）

- 任意席を空席に設定し保存/復元できる。
- ゾーンを追加/名称変更/削除でき、席に割当てられる。
- 生徒は1グループのみ所属（多重所属はUIで防止）。
- 「人一人挟む」が前後左右のみ対象（斜め除外）とUIで明示。
- 全体/グループ内シャッフルでプレビュー→確定できる。
- 設定画面を非表示にして公開画面のみ提示できる。
- LocalStorageで再読込後も状態保持。
- Excel/JSONでバックアップ/復元可能（MVPはエクスポート優先）。

## 10. リスク / 後続検討

- 条件充足不可の説明方法（ユーザーに分かる文言）。
- Excelスキーマの確定と互換性維持。
- 演出強化と計算分離（将来Web Worker）。
- タブレット最適化・PWA化。
