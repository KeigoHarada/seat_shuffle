# 席替え支援Webアプリ 技術スタック選定

最終更新: 2025-10-05

---

## 1. 要件から導出される技術要件

- **静的サイト**: GitHub Pages配信（サーバー不要）
- **ローカル完結**: 外部API不要、LocalStorage永続化
- **直感的UI**: ドラッグ&ドロップ、リアルタイム更新
- **印刷最適化**: A4対応、CSS印刷メディアクエリ
- **将来拡張**: タブレット対応、PWA化の余地
- **開発効率**: 教師が使うため、バグが少なく保守しやすい

## 2. フレームワーク選定の比較

### 2.1 候補フレームワーク

| フレームワーク | 学習コスト | バンドルサイズ | 印刷対応 | 将来性 | 総合評価 |
|---------------|-----------|---------------|----------|--------|----------|
| **Vanilla JS** | 低 | 最小 | 良好 | 高 | ⭐⭐⭐ |
| **Vue 3** | 中 | 小 | 良好 | 高 | ⭐⭐⭐⭐⭐ |
| **React** | 中 | 中 | 良好 | 高 | ⭐⭐⭐⭐ |
| **Svelte** | 中 | 最小 | 良好 | 中 | ⭐⭐⭐⭐ |
| **Angular** | 高 | 大 | 良好 | 高 | ⭐⭐ |

### 2.2 採用: **React 18 + TypeScript**

**選定理由:**

- **エコシステム**: 豊富なライブラリ、コミュニティ
- **将来性**: Meta主導、長期的な安定性
- **開発効率**: JSX、コンポーネント指向
- **印刷対応**: CSS-in-JSまたは標準CSS選択可能
- **学習コスト**: 広く使われており、情報が豊富
- **パフォーマンス**: Concurrent Features、Suspense

**特に適している理由:**

- 席配置の状態管理が明確
- 条件設定の複雑なロジックに対応
- 設定/公開画面の分離が容易
- コンポーネント再利用性が高い

## 3. 技術スタック（確定）

### 3.1 フロントエンド

- **フレームワーク**: React 18
- **ビルドツール**: Vite
- **状態管理**: Zustand
- **ルーティング**: React Router（画面切替用）
- **スタイリング**: CSS Modules + CSS Custom Properties
- **アイコン**: Lucide React（軽量、統一感）

### 3.2 開発ツール

- **言語**: TypeScript
- **リンター**: ESLint + React ESLint Plugin
- **フォーマッター**: Prettier
- **テスト**: Vitest + React Testing Library（将来）

### 3.3 ライブラリ（必要最小限）

- **Excel処理**: SheetJS (xlsx)
- **日付処理**: date-fns（軽量）
- **ユーティリティ**: lodash-es（必要部分のみ）

### 3.4 デプロイ

- **ホスティング**: GitHub Pages
- **CI/CD**: GitHub Actions
- **ドメイン**: カスタムドメイン（任意）

## 4. アーキテクチャ方針

### 4.1 ディレクトリ構成

```
src/
├── components/          # 再利用可能コンポーネント
│   ├── common/         # 汎用コンポーネント
│   ├── seat/           # 席関連コンポーネント
│   └── student/        # 生徒関連コンポーネント
├── views/              # ページコンポーネント
├── stores/             # Piniaストア
├── composables/        # 再利用可能ロジック
├── utils/              # ユーティリティ関数
├── types/              # TypeScript型定義
└── assets/             # 静的ファイル
```

### 4.2 状態管理方針

- **Zustandストア**: 席配置、生徒データ、条件設定
- **LocalStorage**: 自動保存、スキーマバージョン管理
- **リアクティブ更新**: 設定変更時の即座反映

### 4.3 パフォーマンス方針

- **コード分割**: ルートベースの遅延読み込み
- **仮想化**: 大量席配置時の表示最適化（将来）
- **Web Worker**: シャッフル計算の分離（将来）

## 5. 開発環境セットアップ

### 5.1 必要ツール

- Node.js 18+
- npm/yarn/pnpm
- VS Code + React拡張

### 5.2 初期セットアップ

```bash
npm create vite@latest seat-shuffle -- --template react-ts
cd seat-shuffle
npm install
```
