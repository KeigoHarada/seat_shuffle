# 席替え支援Webアプリ デザインルール

最終更新: 2025-10-05

---

## 1. デザインコンセプト

### 1.1 基本方針

- **Apple Human Interface Guidelines準拠**: 直感的で一貫性のあるユーザー体験
- **学校風デザイン**: 親しみやすく、教育現場に適した視覚的表現
- **アクセシビリティ重視**: 誰でも使いやすい、包括的なデザイン
- **モダンな洗練**: 現代的で美しいインターフェース

### 1.2 デザイン原則

1. **明確性**: 情報の階層と重要性を視覚的に表現
2. **一貫性**: 統一されたデザイン言語の使用
3. **効率性**: 最小限の操作で最大の効果
4. **美しさ**: 機能的でありながら美しいデザイン

## 2. タイポグラフィ

### 2.1 フォント選定

- **プライマリフォント**: [コトノル](https://kotonohaworks.com/kotonoru.html)
  - モダンでスタイリッシュな日本語フォント
  - 10段階のウェイト（Thin〜Black）
  - 商用利用可能、JIS第二水準漢字対応
  - 学校風デザインに最適な落ち着いた佇まい

### 2.2 フォント階層

```css
/* ディスプレイ - メインタイトル */
.display { font-size: 3rem; font-weight: 700; line-height: 1.2; }

/* タイトル1 - ページタイトル */
.title1 { font-size: 2.5rem; font-weight: 600; line-height: 1.3; }

/* タイトル2 - セクションタイトル */
.title2 { font-size: 2rem; font-weight: 600; line-height: 1.3; }

/* タイトル3 - サブセクション */
.title3 { font-size: 1.5rem; font-weight: 500; line-height: 1.4; }

/* ヘッドライン - カードタイトル */
.headline { font-size: 1.25rem; font-weight: 500; line-height: 1.4; }

/* ボディ - 本文 */
.body { font-size: 1rem; font-weight: 400; line-height: 1.5; }

/* コールアウト - 説明文 */
.callout { font-size: 0.875rem; font-weight: 400; line-height: 1.4; }

/* サブヘッドライン - ラベル */
.subheadline { font-size: 0.875rem; font-weight: 500; line-height: 1.4; }

/* フットノート - 補足情報 */
.footnote { font-size: 0.75rem; font-weight: 400; line-height: 1.3; }
```

## 3. カラーシステム

### 3.1 セマンティックカラー

- **プライマリ**: 青系（信頼性、安定性）
- **セカンダリ**: グレー系（中立性、バランス）
- **サクセス**: 緑系（成功、完了）
- **ワーニング**: 黄系（注意、警告）
- **エラー**: 赤系（エラー、危険）

### 3.2 学校風カラー

- **黒板**: 深いグレー（#2d3748）
- **チョーク**: 明るいグレー（#f7fafc）
- **ゾーン色**: 各ゾーンを区別する色分け

### 3.3 アクセシビリティ

- **コントラスト比**: 最低4.5:1、推奨7:1
- **色覚対応**: 色だけでなく形状・テキストでも情報を伝達

## 4. スペーシング

### 4.1 基本単位

- **ベース単位**: 4px（0.25rem）
- **スケール**: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64px

### 4.2 セマンティックスペーシング

- **xs**: 4px - 密接な要素間
- **sm**: 8px - 関連要素間
- **md**: 16px - 標準的な要素間
- **lg**: 24px - セクション間
- **xl**: 32px - 大きなセクション間

## 7. アニメーション

### 7.1 基本原則

- **目的**: 状態変化を視覚的に伝達
- **時間**: 150ms（高速）、300ms（標準）、500ms（低速）
- **イージング**: ease-out（自然な動き）

### 7.2 シャッフル演出

- **時間**: 2秒間
- **効果**: 席が高速で入れ替わる
- **イージング**: ease-in-out（加速→減速）

### 7.3 インタラクション

- **ホバー**: 0.2秒でスケール・シャドウ変化
- **クリック**: 0.1秒でスケールダウン
- **フォーカス**: アウトライン表示

## 8. アクセシビリティ

### 8.1 キーボードナビゲーション

- **Tab順序**: 論理的な順序でフォーカス移動
- **フォーカス表示**: 明確なアウトライン
- **ショートカット**: Ctrl/Cmd + S（設定切替）

### 8.2 スクリーンリーダー

- **セマンティックHTML**: 適切なタグ使用
- **ARIA属性**: 状態・役割の明示
- **代替テキスト**: 画像・アイコンの説明

### 8.3 色覚対応

- **色以外の手がかり**: 形状・テキスト・アイコン
- **コントラスト**: 十分な明度差
- **パターン**: 色分けに加えてパターン使用
