# 席替え支援Webアプリ 画面設計（ワイヤーフレーム）

最終更新: 2025-10-05

---

## 1. 画面構成概要

### 1.1 画面分類

- **公開画面**: 生徒向け表示（設定要素非表示）
- **設定画面**: 教師向け編集・管理機能

### 1.2 画面一覧

1. **公開画面** - 席表表示・シャッフル結果
2. **設定/席配置** - レイアウト編集・ゾーン管理
3. **設定/生徒管理** - 生徒・グループ・班長設定
4. **設定/条件設定** - シャッフル条件・ルール
5. **設定/データ管理** - 保存・復元・Excel入出力

## 7. 画面遷移フロー

### 7.1 基本フロー

```
公開画面
    ↓ [設定切替]
設定メニュー
    ├─ 席配置
    ├─ 生徒管理
    ├─ 条件設定
    └─ データ管理
```

### 7.2 設定画面内遷移

```
席配置 → 生徒管理 → 条件設定 → データ管理
   ↑                                    ↓
   └────────── 公開画面 ←────────────────┘
```

### 7.3 キーボードショートカット

- `Ctrl/Cmd + S`: 設定画面表示切替
- `Ctrl/Cmd + P`: 印刷
- `Ctrl/Cmd + F`: 全画面表示
- `Esc`: 設定画面から公開画面へ
